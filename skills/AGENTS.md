# skills — 第三方 skill

本目錄只放**第三方**可攜 skill，依上游原樣保存。給維護這個目錄的人與 Agent 看；分類與上游來源見 [`README.md`](README.md)。

## 規則

- **不改內容**。只從可追溯的上游來源同步更新，保留原始授權與 attribution 檔案。
- 不混入組織或專案專屬規則；那類內容放 [`../my-skills/`](../my-skills/)（自建獨立 skill）或 [`../my-plugins/`](../my-plugins/)（plugin）。
- 分類目錄（`design/`、`react/` 等）只用來區隔，本身不是 skill。
- 更新前檢查上游授權、版本與相依資產是否一併變動；更新後同步 `README.md` 的分類表。
- 不要對整個 repo 一次安裝全部 skill；需要哪個就單獨取用哪個。
