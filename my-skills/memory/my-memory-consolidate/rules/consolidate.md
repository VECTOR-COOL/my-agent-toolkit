# 記憶整理規則

使用 `my-memory-consolidate` 時讀。流程以 [`../SKILL.md`](../SKILL.md) 為準。

- 只處理這一批取回的筆。有界掃描、不整庫掃描、不為整理再搜一次、不逐筆補讀；每批最多 N 筆（預設 100）。
- 起始權重 `1`（沒有 `weight` 或舊值 `normal` 都當 `1`，舊值 `high` 當 `3`）。權重只在**合併重複**時增加：`max(原權重) + 被合併掉的筆數`。
- `weight` ≥ 3 只列入升長期建議；寫長期庫與刪 Mem0 須使用者同意，排程執行時不做。還在改的任務狀態最多升中期。
- **遺忘**：`weight` ≤ 1 且最舊的 `created_at` 滿 30 天，兩項都成立就必須刪除該組全部 id，不先問，刪完列出 id、摘要、權重、存放天數。隱藏、`expiration_date`、降權重都不算遺忘。沒有 `created_at` 不遺忘，也不猜日期。
- `tier=long` 的長期索引筆不加權、不遺忘、不合併。
- 憑證、token、金鑰、付款資料不加權，也不合併、不寫進長期、不出現在回報。
- 不能寫 metadata 時，這次不合併、不加權、不升層；遺忘條件成立仍要刪，刪除失敗要明講。
- 額度或速率錯誤就停止並回報接續點，不重試轟炸。
