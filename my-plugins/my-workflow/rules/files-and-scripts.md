# 腳本、臨時檔與設定檔規則

寫腳本、產生測試檔或一次性檔案、編輯設定檔前讀。

**腳本**
- 專案新腳本用 `.mjs`，優先用 Node 內建 API，沒有具體需要不加 npm 套件。不新寫 PowerShell 或 Python（只限專案自己的程式，既有第三方不改）。
- 會改檔的腳本要有 `--help`、非零失敗碼，預設不覆寫既有檔。

**臨時產物**
- 測試檔、一次性腳本、驗證輸出、跑指令的 error log 放專案約定的臨時目錄，沒有約定就用 `scripts/tmp/`；log 檔名 `<用途>-<日期>.log`（如 `build-error-2026-10-31.log`）。不寫進執行期 log 目錄（`log/` 或框架路徑），那是程式的。
- 自己產生且不再需要的，結束時清掉並列清單，中斷後恢復時先清；來源不明的先列清單，同意後才刪，要保留就移到正式目錄。

**設定檔**
- 需保留縮排、換行、註解（如 JSONC）時用區塊編輯；禁止 minify／單行整檔覆寫、無縮排的 `JSON.stringify` 整檔取代、stdout 重導向覆蓋。驗證只 parse，不寫回。
