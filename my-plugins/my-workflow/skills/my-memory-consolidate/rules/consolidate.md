# 記憶整理規則

使用 `my-memory-consolidate` 時讀。流程以 [`../SKILL.md`](../SKILL.md) 為準。

- 只處理這次查詢已命中的筆。不整庫掃描、不為整理再搜一次、不逐筆補讀。
- 起始權重 `1`（沒有 `weight` 或舊值 `normal` 都當 `1`，舊值 `high` 當 `3`）。每次查詢，同一組只加 `1`。
- 加權後 `weight` ≥ 3 才可升長期；升長期須使用者同意，且長期寫入並讀回成功後才刪 Mem0。還在改的任務狀態最多升中期。
- **遺忘**：`weight` ≤ 1 且最舊的 `created_at` 滿 30 天，兩項都成立就必須刪除該組全部 id，不先問，刪完列出 id、摘要、權重、存放天數。隱藏、`expiration_date`、降權重都不算遺忘。沒有 `created_at` 不遺忘，也不猜日期。
- 憑證、token、金鑰、付款資料不加權，也不寫進長期。
- 不能寫 metadata 時，這次不加權、不升層；遺忘條件成立仍要刪，刪除失敗要明講。
