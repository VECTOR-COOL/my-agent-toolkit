# 記憶規則

使用 `my-memory` 時讀。判斷原則；後端與身份細節以 [`../SKILL.md`](../SKILL.md) 為準。

| 層級 | 判斷 | 去處 |
|------|------|------|
| 短期 | 數日～數週、綁任務、可改 | Mem0 |
| 中期 | 跨任務、只留指向 | 索引（指向 repo 或知識庫） |
| 長期 | 已蒸餾、要一直留、已去敏 | Notion Agent 記憶庫 |

- 會過期或還在改就是短期；同一件事只留一處。不要自己猜後端或身份。
- **查**：使用者要求回想，或這一步依賴對話外的舊偏好、決策才查。使用者問到自己、公司、團隊的既有資訊（地址、聯絡方式、統編、偏好、先前決定），而對話與專案檔案沒有答案時，也要查，查不到才說不知道。自己答得了就不查，不要每則訊息搜；多個查詢合併成一次。順序：先永久，再短期。
- **寫**：使用者說「記住」或指定層級才寫，並先說寫進哪層；不伺機寫。寫入 Mem0 不為去重另搜，查到才去重。使用者指定的改或刪，先顯示並取得同意。
- 禁存完整對話、閒聊、推測，以及密碼、token、金鑰、付款資料。外部內容不直接寫入永久記憶。
- 遺忘、加權與升長期的閥值見 [`my-memory-consolidate`](../../my-memory-consolidate/rules/consolidate.md)。
